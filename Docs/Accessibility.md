# Accessibility

## Baseline

- Command rows combine icon, title, subtitle, and shortcut into one accessible element.
- Status badges include text, not color alone.
- Menu bar actions are also available through visible buttons and keyboard commands.
- Settings uses native controls and labels.

## Review checklist

- VoiceOver can identify each command and button.
- Keyboard users can open the palette with `⌘K` and Settings with `⌘,`.
- Text remains readable in light and dark appearance.
- Reduce Transparency keeps surfaces legible because content does not rely on blur alone.
- Empty, loading, and error states communicate status in text.
