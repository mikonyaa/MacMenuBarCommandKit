# Roadmap

Close the recorded native gates for final 0.3.0: authenticated XCUI/keyboard/focus/system-menu journeys, VoiceOver/reduced-motion readability, owned signed Launch at Login, real sleep reconciliation and minimum-OS runtime evidence. Keep the [validation record](Docs/Validation-0.3.0-rc.1.md) factual.

Optional later additions should have a demonstrated adopter need: App Intents example, documented no-Dock mode, localization sample, app icon/distribution recipe. Session inbox persistence would be a separate app-owned feature with an explicit data/lifetime contract. Notification authorization is not a current feature or placeholder. Investigate performance only after a measured problem; no cache or scheduler framework is planned.
